# displacements_prediction
# Shape Regression with Foundation Models

This project investigates landmark-based shape regression on chest X-ray images using pretrained visual foundation models and deep learning architectures. The objective is to refine an initial estimate of anatomical landmark locations by predicting displacement vectors that move each landmark toward its ground-truth position.

The dataset consists of 247 chest X-rays from the JSRT dataset, each annotated with 166 anatomical landmarks. During training, an initial shape is generated by perturbing the ground-truth landmarks with Gaussian noise. The model then learns to predict the displacement required to recover the true landmark positions.

Three approaches were implemented and evaluated:

### Task 1 – Local Landmark Regression

A pretrained DINOv2 backbone extracts dense image features. Local feature vectors are sampled at the landmark positions using differentiable grid sampling and passed to a lightweight MLP that predicts landmark displacements independently.

### Task 2 – Context-Aware Landmark Regression

The local landmark features are processed by a Transformer encoder, allowing information exchange between landmarks. This enables the model to leverage global shape context and spatial dependencies when predicting displacements.

### Task 3 – Implicit Shape Representation

A conditional SIREN (Sinusoidal Representation Network) is used to model landmark displacements as a continuous coordinate-based function. The model receives landmark coordinates together with image-derived conditioning features and predicts shape refinements through an implicit neural representation.

## Evaluation

Models are evaluated using Target Registration Error (TRE), defined as the average Euclidean distance between predicted and ground-truth landmark positions. In addition, shape smoothness is measured using second-order landmark differences to assess contour regularity.

## Technologies

* PyTorch
* DINOv2 Vision Transformer
* Transformer Encoder
* SIREN (Implicit Neural Representation)
* Differentiable Grid Sampling
* GPU-accelerated Training

The project was developed as part of the "Shape Regression with Foundation Models" challenge at the Institute of Medical Informatics (IMI), University of Lübeck.
